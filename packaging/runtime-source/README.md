# Local emulator core source record

This directory preserves the source evidence for the locally tested arm64
runtime. It is **not a determination that corresponding-source or all other
redistribution obligations have been met**; see
[the provenance review](../../docs/runtime-provenance-local.md).

- Upstream: AOSP `platform/external/qemu`, commit
  `5e51202879523d4df1bca8ca6944129ff05df02b`.
- `qemu-local.patch` records the six modified source/build files. It is a
  separate third-party source patch under the applicable upstream QEMU file
  licences, not part of the Apache-licensed Rust crates. `LICENSE-qemu.txt`,
  `COPYING-GPL-2.0` and `COPYING-LGPL-2.1` are copied from that checkout.
- `aosp-checked-out.xml` pins the HEADs of projects actually present during
  this local build. Projects not present, including the optional system-images
  checkout and other host platforms, were omitted. The pinned manifest and
  build have not been verified from a clean checkout.
- `NOTICE-core.txt` and `NOTICE-core.csv` are notices generated by the AOSP
  build tree, and must be reviewed along with the notices supplied with the
  Google runtime and platform tools.
- The source snapshot and several dependency archives remain in the local
  source candidate. A complete corresponding-source package, dependency mapping,
  build instructions and an ongoing source-access mechanism are still required
  before publication.

The observed local build used the AOSP `android/build/python/cmake.py` wrapper
with `--target darwin-aarch64`, revision `37.3.10`, CMake Release mode and
Ninja target `qemu-system-aarch64-headless`. It used Xcode's macOS 27.2 SDK and
Apple linker. `qemu-local.patch` includes a machine-specific linker path; the
recorded recipe and pinned manifest are starting points, not a demonstrated
portable rebuild. Exact build dependency and corresponding-source review is
still required.
