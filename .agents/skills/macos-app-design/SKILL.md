# macOS App Design

Use the existing project design system, platform support, and user requirements as the source of truth. Assess only the visual and interaction concerns relevant to the requested work; do not introduce a new architecture or redesign unrelated surfaces.

For detailed patterns, examples, and checklists, consult [the macOS design guide](references/design-guide.md) selectively for the relevant sections. Its values and app comparisons are suggestions, not requirements. Use a relevant HIG skill when Apple design guidance is needed, and SwiftUI or AppKit skills when implementation needs their workflows.
