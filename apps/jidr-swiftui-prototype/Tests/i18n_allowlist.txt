# Localization baseline allowlist for the SwiftUI/AppKit prototype.
#
# The M0 audit (docs/swiftui-localization.md) found Chinese user-visible
# strings that the three mechanisms cannot translate, so English mode renders
# them verbatim. Tests/localization_coverage.py fails on every finding that is
# NOT listed here, which keeps a new untranslated string from landing silently.
# When a finding is gone the gate reports the row as stale - delete it then.
#
# Format, fields separated by " | ":
#   <repo-relative path>:<line> | <rule> | <literal> | <audit id + why it leaks> | <fix>
#
# Matching uses (path, rule, literal); the line is informational, so moving code
# around does not invalidate the baseline. A row also pins how many occurrences
# of that literal the audit found (default 1, override with a trailing
# "occurrences=N" field); a new copy of a baselined literal in the same file is
# still reported as a new leak.
#
# M3 close-out: the bridge diagnostics (17 rows), the player/key-map/log-stream/
# window-quality dynamic errors (8 rows) and the device-center AppKit/dynamic
# strings (10 rows) are fixed, so their rows were removed. What remains is one
# file owned by the native-integration line:
#   4 rows: Sources/GameWindowState.swift errorDescription copy (E2 in the M0
#   audit). It is the native line's write scope, not the M3 localization line's.
# Baseline: 4 findings / 4 occurrences. The gate reports stale rows, so deleting
# them here is the only follow-up once that file is cleared.
#
# Rules, for reference:
#   strings-key      Chinese literal used as LocalizedStringKey with no en.lproj entry
#   appkit-sink      plain-String AppKit sink (title/save-panel/accessibility/toolTip)
#   appkit-a11y      accessibilityValue(variable) bypassing localized()
#   dynamic-sink     rendered String variable assigned a Chinese literal
#   exposed-error    Chinese text that becomes a user-visible error description
#   player-status    player status bubble literal without en key or localized() prefix
#   bridge-diagnostic  Chinese diagnostic in a bridge binary (player or center)
#
# --- E: Swift dynamic errors (LocalizedError / NSError -> UI text) ---------
