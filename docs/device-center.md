# JIdr Plus 0.4 设备中心指南

设备中心用于管理设备、应用和快照；运行中的 Android 画面显示在独立游戏窗口中。设备状态由 Rust daemon 管理，界面通过现有协议命令操作设备。

## 选择与操作设备

在左侧原生侧边栏搜索或选择设备。右侧概览顶部提供启动、打开设备窗口、停止、设备设置和设备工具；运行时显示截图、录屏与发送文件的小按钮。“更多”菜单保留重启、删除及进行中的 Root 配置入口。删除仍需确认。

概览的应用卡片提供搜索、启动应用、选择 APK 和拖入安装；“管理应用”始终保留入口，设备运行后可打开完整列表。快照卡片集中提供创建和管理。停止状态下，运行设备才能使用的操作会停用。

设备信息只读展示 Android、CPU、内存、分辨率、DPI、磁盘占用及 Root 状态。展开高级信息可查看设备 ID、SDK 路径、连接端口和会话信息。窄窗口自动改为上下排列，页面可滚动。

## 设备设置与摄像头

设备设置保存名称、硬件、快速启动、自动休眠、声音和游戏窗口画质。硬件与启动设置通常需要先停止设备。修改后点“保存”才提交；取消保留原值。

摄像头来源统一在“设备工具 → 摄像头”中编辑。设备设置中的摄像头链接会打开同一个工具页面，保留设置表单的其他未保存内容。在摄像头页面修改前后置来源后点“应用”，下次启动设备生效。

## Root 与系统分区写入

“设备工具 → Root 管理”集中提供模式切换、验证、Magisk 模块、设备标识、系统证书和系统分区设置。完整 Root 的模块、标识和证书操作与 Shell Root 的系统写入属于不同能力。

启用 `/system` 写入要求 Shell Root、Android 12（API 31）及以上、镜像支持 adb root。运行时切换会立即冷启动；停止时切换在下次启动应用。操作前会显示确认提示，请先保存游戏进度。

“恢复只读”会移除系统写入覆盖层并恢复原始系统，覆盖层中的系统修改会丢弃。页面显示后台保存的配置状态，不代表刚刚执行过实时文件系统探测。更多限制见 [Root 文档](root.md)。

## 用音频文件模拟麦克风

在“设备工具 → 麦克风”选择本机 WAV 文件，按需开启循环并开始播放。支持单／双声道、8–48 kHz WAV；设备需运行且启用声音，Android 应用需打开麦克风接收音频。

此功能播放音频文件，不是 Mac 实时麦克风透传。关闭工具面板或切换页面后，任务仍可继续；重新打开页面可以停止，也能发现由 CLI/MCP 启动的注入任务。停止会等待任务确认结束；即使文件仍在读取，也会取消对应任务。

## 版本与验证范围

本指南对应 JIdr Plus 0.4.0 源码。后台 API 沿用已有的 `root.writable_system`、`audio.inject`、`audio.stop` 和任务协议，没有新增 wire-format 变更。

逻辑测试、后台截图及应用构建用于检查状态处理、布局和打包。它们不等同于真实模拟器上的系统写入／音频接收验收，也不证明所有游戏兼容或发行公证已完成。可复现命令见 [SwiftUI 开发说明](../apps/jidr-swiftui/README.md#verification)。
